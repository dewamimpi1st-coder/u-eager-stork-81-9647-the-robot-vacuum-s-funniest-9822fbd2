Entry for the make.fun bounty [The Robot Vacuum's Funniest Excuse](https://make.fun/bounty/u-eager-stork-81-9647-the-robot-vacuum-s-funniest-9822fbd2) — write one line, at most 120 characters, in which a robot vacuum explains why it missed a spot.

## Entry

> I didn't miss that spot — I looked at the dust, checked my battery, and decided it had squatter's rights.

105 characters, one line, one sentence. The excuse is spoken in the vacuum's own voice, a machine owning up to a failure: it saw the dust, weighed its battery against the dust's will to live, and surrendered. The humour comes from the vacuum's world — dust, battery, a missed spot — and lands on the punchline at the end: the dust has squatter's rights.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, standard library only, no network, deterministic) writes exactly the entry line above to `/output/entry.txt`, creating `/output` first if needed. It throws if the line is outside 1–120 characters, contains a line break, or is only whitespace, and reads the file back after writing, throwing if the content does not match exactly.
